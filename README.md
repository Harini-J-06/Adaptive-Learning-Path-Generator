# Adaptive Learning Path Generator

A personalized learning platform that generates adaptive learning roadmaps based on a user's learning goal, skill level, and available study time.

## Project Overview

The Adaptive Learning Path Generator helps learners create a structured learning journey based on their individual needs.

Instead of following the same learning path for everyone, the application generates a roadmap according to:

- Learning Goal
- Skill Level
- Available Study Time

Each learning roadmap contains different modules that guide the learner step by step.

## Features

- User registration and login
- Personalized learning path generation
- Learning goals and skill-level selection
- Study-time based roadmap generation
- Video lessons for learning modules
- Quizzes to test understanding
- Learning progress tracking
- User-friendly web interface
- Database-driven application

## Technologies Used

- *Python*
- *Flask*
- *SQLite*
- *HTML5*
- *CSS3*
- *JavaScript*
- *Jinja2*

## How It Works

1. Create an account or log in.
2. Enter your learning goal.
3. Select your current skill level.
4. Specify your available study time.
5. The system generates a personalized learning roadmap.
6. Select a module from the roadmap.
7. Watch the video lesson.
8. Complete the quiz for the module.
9. Track your learning progress.

## Getting Started

Follow the steps below to run the Adaptive Learning Path Generator locally.

## Prerequisites

Before running the project, make sure you have:

- Python 3.x installed
- Flask installed
- A web browser
- Visual Studio Code (recommended)

## Installation

1. Clone this repository:

   git clone https://github.com/Harini-J-06/Adaptive-Learning-Path-Generator.git

2. Navigate to the project folder:

   cd Adaptive-Learning-Path-Generator

3. Install the required Python package:

   pip install flask

4. Run the application:

   python app.py

5. Open the URL shown in the terminal in your web browser.

## Purpose

The purpose of this project is to provide a personalized learning experience by generating adaptive learning roadmaps based on the user's learning goals, skill level, and available study time. It combines structured learning modules, video lessons, quizzes, and progress tracking to help users follow a guided learning path.
